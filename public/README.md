# Görseller

Bu klasöre aşağıdaki dosyaları ekleyin:

- `cift-fotografi.jpg` — Sayfadaki ana çift fotoğrafı. Dikey, 4:5 oranında ve en az 1200×1500 px önerilir.
- `davet-og.jpg` — WhatsApp ve sosyal medya paylaşım görseli. 1200×630 px önerilir.

Dosya adlarını farklı kullanmak isterseniz `index.html` içindeki ilgili yolları güncelleyin.
